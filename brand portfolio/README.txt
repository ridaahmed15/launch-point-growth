LAUNCHPOINT GROWTH — PORTFOLIO WEBSITE
======================================

Forest-green themed portfolio site with animations and interactive features.

Files:
- index.html  — structure and content
- style.css   — forest green theme, layout, animations
- script.js   — menu, scroll reveal, counters, filters, modal, form

How to preview:
1. Open index.html in a modern browser.
2. Internet connection recommended for Google Fonts (Syne + DM Sans).

Features:
- Fixed header that gains blur on scroll
- Animated hero with floating chips, live chart, and stats counters
- Scrolling marquee
- Portfolio grid with category filters and case-study modal
- Service cards, approach timeline, about section
- Contact form (opens email client)
- Mobile-responsive navigation
- Scroll-triggered reveal animations
- Back-to-top button

Theme: deep forest green (#0d1f14) with lime accents (#b8f36b).
